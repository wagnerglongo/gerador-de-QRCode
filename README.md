# Gerador de QR Code

Gera um QR Code a partir de qualquer URL ou texto, direto no navegador.

**🔗 Demo:** https://gerador-de-qr-code-one.vercel.app

## Como funciona

1. Digite uma URL ou texto e clique em **Gerar QR Code** (ou pressione Enter)
2. O código é gerado pela API pública [QR Server](https://goqr.me/api/) e exibido na tela
3. Ao apagar o texto, a área do QR Code é limpa

## Tecnologias

HTML5 · CSS3 · JavaScript · consumo de API REST

## Rodando localmente

```bash
git clone https://github.com/wagnerglongo/gerador-de-QRCode.git
cd gerador-de-QRCode
npx serve .
```
